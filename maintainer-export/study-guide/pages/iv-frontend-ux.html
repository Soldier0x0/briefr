Frontend & UX

React 19, Radix, semantic tokens, DetailDrawer patterns, and accessibility.

What it does

Q: What chart library is used?

A: Recharts behind ChartShell with fixed-height wrappers and maintainAspectRatio: false. EPSS sparklines remain custom SVG. Chart.js was fully removed.

Q: What motion rules apply?

A: 120–180ms transitions on transform/opacity only; respect prefers-reduced-motion and global data-motion toggle on <html>. No layout property animation.

Q: What is the DataGrid pattern?

A: Shared DataGrid with table-layout: fixed and shared <col> definitions so column resize keeps header/body aligned.

Q: What accessibility baseline?

A: WCAG 2.1 AA: focus rings via --focus-ring, icon-only controls need aria-label, interactive targets ≥24px. Tooltips explain status pills—design principle 1.

Q: What is dark-mode-only policy?

A: Light theme removed (W6)—do not reintroduce without ADR. tokens.css assumes dark surfaces; contrast uses --text-muted floor.

Q: How is stack input persisted?

A: GET/PUT /api/me/stack with legacy briefr_stack localStorage migration on login. Feed filter bar and asset wizard consume server stack.

Core implementation

Q: How are colors managed?

A: Semantic tokens only: --surface-*, --text-*, --severity-*, --accent-selected for active states. Red is destructive/critical only—not for links or selection. Brand orange #e85533 via --accent-primary.

Q: How does DateTimePicker work?

A: Shared DateTimePicker / DateTimeRangeField with DD-MM-YY HH:mm:ss and dropdown selects—never native datetime-local in new code per design system §23.

Q: How does admin differ visually?

A: Shared tokens but denser tables via AdminDataGrid, uppercase mono wayfinding breadcrumbs, collapsible config sections, sticky apply bar. Typography enforces 12px minimum via --type-* scale.

Q: How are toasts handled?

A: Shared toast tray: errors persist until dismissed; success auto-dismiss 8s; max 4 visible; pause on hover. Backend restart uses top banner via health poll—not a fleeting toast.

Q: How does URL state work for Forge?

A: ?tab=forge with view, technique, pack params. Intentional navigations push history; cosmetic param hygiene uses replaceState.

Q: What is the Background sync portal UI?

A: Portaled Radix dropdown on header—groups api_queue tasks by provider, distinguishes waiting vs queued, collision-aware (Program A UX RCA). Distinct from Admin durable outbound jobs panel.

Q: What UX RCA changed in the drawer?

A: PR-A: Overview IA, L-edge panels, accent-ghost actions, Active Campaigns default closed, MITRE hint only when techniques exist, tabs stay mounted after first visit. PR-D: Forge matrix EmptyState, honest campaign copy.

Q: What is Track E command palette?

A: ⌘K wayfinding—keyboard accessible, portaled. Part of UI-M design system completion alongside Radix primitives and token lint gates.

Integration

Q: What UI primitives are standard?

A: Radix: Checkbox, Switch, Dialog, Select, Tabs, DropdownMenu, Tooltip, Popover, ScrollArea—styled with design tokens. Zero native <select> or checkbox inputs in new code (grep gates in verify-local).

Q: How does the command palette work?

A: ⌘K command palette (Track E) for wayfinding—portaled, keyboard accessible. Global shortcuts ignore modifiers when text is selected; drawer and tab state preserved.

Q: How would you add a new analyst page?

A: Follow Primitives → Composites → Features layering, reuse Radix + tokens, implement four async states, wire URL tab sync if needed, and update design-system.md if introducing a new pattern.

Q: How does shell URL history interact with Back button?

A: Intentional tab/Forge/admin page/CVE drawer changes push history; cosmetic param hygiene replaces. Back closes drawer before leaving tab; Forge→CVE uses router navigate not location.assign.

Failure modes & edge cases

Q: What is the async region pattern?

A: Every async view implements loading skeleton, empty, error with request-id, and data states. Empty and error must look distinct. Long LOCKED jobs show progress message plus indeterminate bar.

Performance

Q: What is FEED performance work?

A: Scroll isolation, content-visibility: auto windowing (I15), keyset pagination, parallel drawer bundle fetches. Filters and scroll survive tab hidden panels.

Security

Q: How is auth wired in the frontend?

A: AuthContext bootstraps via fetchMe() only—never bare refresh on load. RequireAuth wraps analyst routes matching backend session gate (#441).

Q: What lint gates protect UI quality?

A: verify-local.sh runs design-token lint, native control grep gates, frontend build, and scoped ESLint on scoring + admin pages.

Architecture tradeoffs

Q: Why no Tailwind?

A: ADR-003 mandates plain CSS with semantic tokens in tokens.css—dark terminal identity, no Tailwind runtime. shadcn patterns are reference-only, re-skinned to BRIEFR CSS. Mantine/MUI/Chakra are prohibited per ADR-005.
