ML & embeddings

pgvector retrieval, LLM router, pacing, and what ML does not own in BRIEFR.

What it does

Q: What entities get embedded?

A: CVEs, ATT&CK techniques, and non-retracted correlation_campaigns (E8). content_hash drift triggers re-embed on scheduled backfill. Caps: ingest max 25, backfill max 2000 per run.

Q: Describe the LLM provider router.

A: Scheduler-side chain: Groq → Cerebras → OpenRouter free tier → Gemini, centralized in ai/model_catalog.py. PDF summaries and product extraction use the router. Anthropic was removed from the chain.

Q: What is detection context LLM (K4)?

A: detection_context_llm job extracts paths, params, keywords from CVE/exploit text into feed_cache keys detection_ctx:{cve_id}. Disabled by default (DETECTION_CONTEXT_LLM_ENABLED=0); restart required to register job.

Q: What quotas does AI-3 expose?

A: Advisory snapshots from provider rate-limit response headers in ai/quota.py. Surfaced on AI Operations provider rows and overview quota_warnings—informational, not hard enforcement.

Q: What is NOT done with LLMs?

A: Threat/OP scores are rule-based, not LLM-generated. Generic detection dumps are suppressed. No unauthenticated summarization endpoints. LLMs assist optional enrichment and operator-facing PDF summaries.

Core implementation

Q: Are embeddings required?

A: No. EMBEDDINGS_ENABLED=1 gates nightly embeddings_backfill and semantic search. Requires pgvector on Postgres 16. Retrieval only—no RAG chat over CVE corpus in the core product.

Q: How does hybrid semantic search work?

A: /api/search/semantic combines vector similarity with stack/severity/KEV filters. FEED renders Techniques / Campaigns / CVEs sections. My Stack context stays on during hybrid mode.

Q: Is vision used?

A: Deferred until image inputs exist in the pipeline. Router supports text tasks today; Cerebras gemma vision noted for future detection artifact extraction.

Q: How does retrieval health reporting work?

A: GET /api/admin/retrieval/health shows embedding counts by entity, pending work, extension presence, last backfill. Coupled to AI ops panel—not a separate silo.

Integration

Q: How does Nuclei parsing relate to ML?

A: Deterministic Nuclei YAML parser (D4) enriches detection context artifacts on exploit sync—default on. LLM extract is an optional overlay, not the primary path.

Q: How do embeddings interact with catch-up?

A: Catch-up tick includes embeddings backfill when enabled, along with correlation precompute and CPE catalog sync—subject to existing gates and locks.

Failure modes & edge cases

Q: How do empty LLM responses degrade?

A: Blank bodies count toward circuit health. Scheduler jobs use llm_job_session() to skip a failing provider for remaining CVEs in that run while still failing over on first empty response.

Q: What models are defaults in 2026?

A: OpenRouter free Gemini Flash-Lite IDs went stale; catalog SSOT updated to working IDs. Operators should clear old OPENROUTER_MODEL_* env overrides so defaults apply.

Performance

Q: What is <code>EMBEDDINGS_AUTO_ON_INGEST</code>?

A: Defaults on when embeddings enabled—new/changed CVEs enqueue embed work on ingest. Admin can disable auto-on-ingest independently. CPU-only local embedding model—no GPU requirement documented.

Q: What is LLM pacing (K5)?

A: ai/llm_pacing.py holds ~85% headroom below provider RPM/TPM ceilings. Prevents burning quotas during batch jobs. Catch-up mode raises headroom temporarily.

Security

Q: What gets logged in <code>ai_operations</code>?

A: Redacted metadata per chat_completion_task attempt—no prompt text by default. Token counts when providers return usage. Admin AI Operations page: Overview, Providers, Models, Usage, Activity tabs.

Q: Can admins replay failed LLM operations?

A: Yes—Program E: view payload and POST .../retry with replay provenance, circuit-open guard unless force=true, and audit entries. Activity rows show has_payload when captured.

Architecture tradeoffs

Q: Why skip LLM calls on empty text?

A: Cost and quota protection—llm_payload.py enforces at router and client layers. Prevents noop provider HTTP when CVE description or exploit text is blank.

Q: How would you answer 'why local embeddings vs API-only'?

A: Local CPU embeddings keep recurring cost predictable for self-hosters and avoid shipping CVE text to a third party for every search. Optional cloud LLMs remain for tasks that need generative output, with explicit operator keys.
