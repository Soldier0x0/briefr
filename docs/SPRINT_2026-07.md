### C3 — Retention/TTL map (audited 2026-07-06)

**Pattern:** read paths enforce TTL via `cached_at` / `fetched_at` filters; physical
deletion is via the daily `cache_retention_cleanup` scheduler job
(`backend/db/cache_retention.py`) plus manual admin purges. Nightly correlation
still bulk-deletes `correlation:v1:` / `correlation:v2:` keys.

| Store | Read TTL | Physical retention / cleanup | Notes |
|-------|----------|------------------------------|-------|
| `ioc_cache` | 6 h | 24 h → daily sweeper | One row per unique IOC looked up |
| `feed_cache` | Per-key (30 min–365 d) | Prefix map in `cache_retention.py` → daily sweeper | `ssvc:` kept 365 d; `greynoise:`/`otx:ioc:` 48 h; default 7 d |
| `sessions` | `expires_at` | Daily `session_cleanup` | Bounded ✓ |
| `otx_cve_pulses` / `otx_pulse_iocs` | 6 h | 7 d → daily sweeper | Dual-written with `feed_cache` OTX keys |
| `epss_history` | N/A (time series) | 90 d → daily sweeper + admin `epss_history_old` | |
| `cve_change_history` | N/A | 90 d → daily sweeper + admin `change_history_old` | Admin purge fixed (`detected_at`, was broken `changed_at`) |
| `cve_exploits` | 6 h–365 d | Per-source replace on scheduled sync | No age-based global prune (acceptable — bounded by corpus) |
| `correlation_temporal` | N/A | Nightly full rebuild | Bounded ✓ |
| `incident_rss:*` / `wallboard:snapshot` | 30 min / 45 s | Bounded key cardinality (overwrite) | |
| `audit_log`, `api_usage`, `webhook_delivery_log` | N/A | None yet | Slow linear growth — cap/rotate deferred (ops concern) |
| `correlation_infrastructure` | — | — | **Dead schema** — no writers/readers; drop in a future migration |

**Deferred (documented, not blocking C3):** CVE-delete cascade for `feed_cache` keys
and `cve_embeddings`; `otx_pulses` dimension table prune; redundant `sploitus:`
`feed_cache` layer vs `cve_exploits` dedup.

   - `useAsync(fn, deps)` → `{ data, error, loading, refreshing,
     retry }`. Owns the AbortController and stale-while-revalidate
     (`refreshing` = loading with previous data still rendered — the
     CVEFeed `.feed-refreshing` behavior, formalized). `fn` is called
     with the current `AbortSignal` as its only argument —
     `useAsync((signal) => fetchData(params, { signal }), [params])` —
     so in-flight requests actually abort on dep change/unmount;
     ignoring the argument is allowed but forfeits cancellation.
     Explicitly not a cache/query layer; `error` is the enriched
     `Error` from `api.js` (`.status`, `.requestId` after A2), passed
     through unswallowed.
   - `<AsyncState loading refreshing error onRetry empty emptyTitle
     emptyAction skeleton>` — explicit flags (no `data == null`
     inference like admin `AsyncSection`), `skeleton` as a prop,
     `refreshing` dims children under `aria-busy` instead of
     unmounting (no skeleton flash). Children: plain JSX for the
     common case, or function-as-children `children(data)` which
     AsyncState invokes only in the data state. Use the function form
     whenever inline expressions dereference `data` (e.g.
     `data.items.map(...)`) — plain JSX children are evaluated by the
     parent even while loading and would crash on `null` data.
     Component children (`<MyList data={data} />`) are safe either
     way, since creating the element does not render it.
   - `<ErrorState error onRetry compact>` — renders the safe `detail`
     message, `ref: <requestId>` as copyable text + link to the admin
     log viewer with `?request_id=` prefilled, and a retry button;
     `role="alert"`; never raw exception objects. The log-viewer link
     follows the §7 router-free rule: the href is built from
     `error.requestId` (or passed via a `logHref` prop) and rendered
     as a plain `<a>` — `ui/` never imports `react-router-dom`. This
     component is the A5 acceptance criterion made structural.
   - `<Modal open onClose title busy size footer>` — wraps
     `useModalLayer(open, ref, { trackDepth: true })` (focus trap,
     focus restore, overlay-depth so one Escape closes one layer);
     `busy` blocks Escape and overlay-click dismissal (the
     PdfExportModal guard, made universal); auto `role="dialog"
     aria-modal aria-labelledby`; body scroll lock. `<ConfirmModal>`
     composes it and keeps the `actionId` →
     `/api/admin/destructive-actions` lookup in an admin-side wrapper
     so `ui/` stays API-agnostic.
   - `<Badge variant explain>` — `explain` is required and renders a
     `<Tooltip>` (hover + keyboard focus + touch, `aria-describedby` +
     `role="tooltip"`, viewport-edge flipping — absorbs admin
     `HelpTip`). Raw `title=` is deprecated on status elements
     (PRODUCT.md principle 1 becomes a props contract, not a review
     catch).
   - `<Button variant="primary|ghost|danger" size busy busyLabel>` —
     `busy` ⇒ disabled + `aria-busy` + label swap; always a real
     `<button>`.

5. **A11y acceptance per component** (browser-verified, keyboard-only,
   before merge): Modal — Tab cycles inside, focus returns to trigger,
   two stacked layers close one per Escape; Toast — `aria-live` region,
   errors persist until dismissed; Tooltip — opens on focus, Escape
   hides, works on touch; AsyncState — loading `role="status"`, error
   `role="alert"`; Button — visible `--focus-ring`; contrast ≥ 4.5:1
   against both theme token sets.

6. **Migration rules:** strangler pattern — legacy classes keep working
   until each feature migrates; pixel parity while migrating (a11y
   fixes are the only allowed visual change); delete a feature's local
   CSS block in the same PR that migrates it (no orphans); DetailDrawer
   adopts primitives during its B4 split, never before.

7. **Flagged, not settled — decide at H1/H2 review:**
   - Toast location: Spec A2+A3 says `components/Toast.jsx`; the `ui/`
     layout implies `components/ui/Toast.jsx`. Either execute A3
     verbatim then relocate with a one-line re-export shim in H2, or
     amend A3 first — maintainer's call, do not improvise a third
     option.
   - Toast ↔ router coupling: keep `ui/` router-free by passing the
     ref link as an href/prop instead of importing `react-router-dom`
     inside `ui/`.
   - Icons: analyst surfaces use text glyphs, admin uses lucide-react;
     primitives take an optional `icon` node and default to the
     text-glyph style so promotions don't smuggle a second visual
     language into the feed.

# Zero-budget operating model

No paid API access is assumed. The loop:

1. **Specs over supervision:** judgment-heavy decisions get encoded in
   this appendix (or an ADR) once; Composer executes against them. If an
   item has no spec and needs a decision, write the decision down first.
2. **CI is the enforcer:** backend tests, Postgres job, audits, and the
   Playwright smoke run on every PR — an agent cannot merge red.
3. **Free reviewers on every PR:** the repo already uses Gemini review;
   keep it, and request a second free bot review where available. Bots
   catch mechanical issues; the specs catch design drift.
4. **Free-tier LLM stack (Track K):** Groq primary; Gemini Flash-Lite +
   Cerebras overflow; OpenRouter `:free` last resort only; no Anthropic.
   Scheduler-side JSON extraction only — not end-to-end Sigma authoring.
5. **Batch the strong-model sessions:** when a subscription session (like
   the one that produced this plan) is available, spend it on review of
   accumulated merged PRs + updating `docs/HANDOVER.md` + writing the next
   specs — never on typing code a spec could have delegated.
6. **Open-source flip unlocks free tooling** (Track F): most code-review
   and CI services are free for public repos.
