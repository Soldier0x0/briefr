This is BRIEFR, open-source vulnerability intelligence you run yourself. Here's what it does.

A background scheduler pulls from NVD, CISA KEV, EPSS, MITRE ATT&CK, AlienVault OTX, ExploitDB, and more into one database.

Every CVE gets a Risk Score out of one hundred. Six weighted factors. Same inputs, same number, every time.

It connects related CVEs through shared threat intel and campaigns, so you're not triaging alone.

Starter detection packs for every CVE. Sigma rules and SIEM queries for Elastic, Splunk, Sentinel, and QRadar. Community rules first. Generated rules are labeled experimental.

Scoring and detection are deterministic. Optional AI handles summaries if you want it. Not required for daily triage.

The software is free. You provide hosting. A small VPS is enough.

BRIEFR. Self-hosted. Open source. Link in bio.
